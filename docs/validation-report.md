# 第二版画面修订与验收

2026-09-27。第一版在美术质量上没有达到用户预期，不能以交互测试通过替代视觉验收。本轮已实际修改地形、材质和光照；当前仍存在高度场造型限制，不宣称达到成熟商业游戏的环境资产精细度。

## 画面变化与证据

- 增加沿岩层方向的多尺度山体起伏，核心网格由原来的约 31 m 间距细化至约 10.4 m；中景约 20.8 m。外围逐步减小细节幅度，保留主峰层次。
- 重做雪岩分布阈值和破碎边缘，使岩壁与积雪更清晰；使用生成的绘制岩石源图进行三向投射和 UV 烘焙，减少竖直岩壁拉伸。
- 增加九张切线空间法线图，导出切线，强度 .32；减轻第一轮试作中过重的颗粒感。
- 重新安排暖色侧光和蓝色补光，细腻档启用 4096² 山体投影，缓存静态阴影。流畅档关闭投影，保留相同基础材质与几何。
- 试作的独立柱状岩块看起来生硬，已移出最终导出，只在隐藏 WORK 中保留实验源。未把它们作为完成的细节交付到网页。

对照：[第一版](../revisions/v1/browser.png)、[本轮最终](final-browser.png)、[最终未压缩基线](v2-final-baseline-browser.png)。飞行检查：[接近](flight-0.png)、[雪鞍](flight-13.png)、[掠峰](flight-26.png)、[入谷](flight-39.png)、[远山](flight-52.png)。另有 [环绕](orbit-1.57.png)、[去色](grayscale-browser.png)、[窄屏](mobile-flight.png)。

生成岩石材质来自内置 imagegen，不是第三方扫描数据；[原图及提示词来源](../textures/provenance.md)均保留。所有山体仍为可环绕的真实网格，未用屏幕背景图替代场景。标准 GLB 材质承载颜色与法线；仅天空使用独立 shader，缺失时回退渐变。

## 源文件与导出

`blender/snow_mountain_world.blend` 重开并成功渲染，[Blender 对照](blender-default.png)保留。几何与雪岩位置和网页一致；Blender 的世界背景与浏览器天空、雾不同，不要求逐像素一致。原有 FPV_Path、高精度修改器源、参考图与工作集合仍可编辑。第一版源文件、模型和主要脚本保存在 `revisions/v1/`。

优化顺序：移除未使用的远景切线 → Meshopt 几何压缩并保存中间 GLB → 颜色 WebP quality 90 → 法线无损 WebP。源 PNG 和基线均保留。压缩前后人工比较主视角与关键飞行画面，未发现明显色块移动或剪影变化；未进行逐像素误差测量。

基线 0 错误、0 警告；16 条信息为没有法线纹理的远景含未使用切线，已从最终资产清除。最终剩余信息是验证器不解码 Meshopt 扩展，因此又在实际浏览器完整加载播放验证。完整证据见 [结构](glb-structure.txt)、[验证器](final-validator.json)、[资产统计与哈希](v2-asset-stats.json)。导出、public、dist 的模型 SHA-256 相同。

生产构建成功。Three.js vendor 约 828 KB 原始 / 211 KB gzip，仍有 Vite 大分块体积提示。GLB 比第一版 6.6 MB 更大，这是几何与材质细节的成本。

## 实际运行检查

测试设备：Apple M5 / macOS 27.0（26A428）；Chromium 153.0.8010.12，ANGLE Metal，headful 浏览器。Blender 5.2.2 LTS，Three.js 0.186.1，Node.js 26.8.1。窗口 1440×1000，画布 1390×816；窄屏模拟 390×844。

| 测量 | 中位帧间隔 | P95 | 其他 |
| --- | --- | --- | --- |
| 默认，DPR 1，186 帧 | 8.3 ms | 9.0 ms | 20 次绘制、1,444,000 可见三角形（含天空） |
| 完整 52 秒航线，6244 帧 | 8.3 ms | 9.2 ms | 终点 8 次绘制、354,464 可见三角形 |
| 细腻 DPR 1.5，有阴影 | 8.3 ms | 8.8 ms | 301 帧 |
| 流畅 DPR 1，无投影 | 8.3 ms | 9.2 ms | 301 帧 |

本机 HTTP、新浏览器上下文、无网络限速；首帧渲染调用完成约 766 ms。这不是 GPU fence 或公网下载测量。rAF 帧间隔相当于约 120 FPS，但不代表所有设备或 GPU 单帧耗时。

全部地形纹理按 RGBA8 加 mip 链估算约 **213.3 MiB**，未包括几何、天空、阴影与驱动开销，未实测 GPU 显存。默认 renderer.info 为 20 geometry / 32 texture，飞行结束为 23 / 35，仅是已初始化资源个数。WebP 不降低解码后的同尺寸纹理内存。

- 正常加载控制台错误 0、请求失败 0；完整飞行到结束通过。
- 暂停时间不变、返回恢复原位置、再次播放、旋转缩放、重置、画质与路线图切换均通过。
- 新航线 105 个间隔 0.5 秒的向下射线全部命中地形，最小垂直间距 **132.33 m**；源高度场逐帧最小约 110 m。此采样不是连续碰撞或镜头近裁剪面证明。
- 窄屏无横向溢出，返回按钮可见；模型失败显示重试，天空失败仍可进入场景。
- 全屏代码使用整页 Fullscreen API，未独立自动化验证系统全屏。

原始实测：[完整航线与交互](browser-verification.json)、[画质对比](quality-verification.json)。

## 仍未解决的视觉与设备限制

主峰仍能看出高度场生成的规则尖脊和部分拉伸坡面；积雪缺少独立雕刻的悬挑与厚度变化，近距离材质在陡面受 UV 采样分辨率限制。某些坡面的雪岩图案仍偏重复，法线细节不能替代几何雕刻。当前改进了原版表面、明暗和轮廓细节，但没有把这些问题描述为已经彻底解决。

没有对实体手机、低端显卡、Safari、Firefox、弱网、长时内存或设备丢失恢复做验证；尤其要注意这版更高的纹理内存。画质“流畅”主要降低像素和阴影成本，不减少纹理内存。

继续修改入口：山形及烘焙在 `scripts/build_world.py`，雪岩路径在 `textures/paint-layout.json`，光雾在 `snow-mountain-web/src/scene.js`。手工编辑 Blender 后使用 `scripts/export_scene.py` 和 `scripts/optimize.mjs`，不要重新运行生成脚本覆盖手工雕刻。
