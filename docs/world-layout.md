# 世界布局与美术配置

## 空间

Blender Z 向上，XY 为地面，设计单位米，原点为主山脊中部。导出器转换 glTF 坐标，不再次旋转。

- Hero：主脊从西南向东北延伸，包含前哨峰、低雪鞍、双刃主峰和东北出口；主峰约 2.8 km 设计高度。西侧大雪坡与东侧裸岩峭面形成不对称轮廓。
- Midground：向东西分叉的脊线、盆地与谷地。用共用的高度函数和边界采样确保地形接合。
- Background：多条错位山链环绕核心，轮廓高低变化，近远材质分别控制细节。完整世界约 30 km 宽，外沿消失在雾中。
- 地形采用设计山脊的 swept profiles 与少量沟槽，不均匀铺满孤立圆锥山。默认有平滑法线，结构面与剪影由几何提供。

## 色板与笔触

雪亮色 #E8E5D8，雪冷色 #8C9FBE，深阴影 #606B8B，暖岩 #807A71，冷岩 #454C5D，远雾 #B8C5D6，天空 #718EA9。

设计雪岩修正保存在 textures/paint-layout.json：每笔有世界坐标路径、宽度、角色。大雪槽、山脊雪檐与裸岩窗均以独立路径指定；修改这些路径可重新烘焙。次级笔触沿地形走向，尺寸约 10–70m；远山减少笔触频率与对比。基础颜色不烘入直射阴影。

标准 Principled/GLB 材质使用 Base Color、高粗糙度非金属表面、克制法线。网页以低强度蓝紫环境补光及西南暖色主光形成冷暖明暗，不使用机械二阶 toon 或全场黑描边。基线风格必须成立。画质切换只改变像素比，不替换色板。

天空为独立生成的绘本天空图，来源与提示词记于 textures/provenance.md；不把山体图片作为地形。

## 相机与航线

Web_Default_Camera 以斜侧面建立主峰、鞍部、谷地和远山。允许环绕，限制距离与最低仰角以避免进入未设计范围。

52 秒原创 FPV_Flight，30fps、1561 帧：南侧广角建立 → 接近雪鞍 → 沿主脊掠峰 → 转入东侧谷地 → 远山揭示。路径以控制点与 Blender FPV_Path 保留，位置/四元数烘焙到 GLB。高度提前检查前方地形，镜头使用平滑前视目标与有限侧倾，避免突然撞壁或仰望天空。

正式美术前先导出低精度 blockout 并在网页核对空间；最终全航线检查实际导出网格、默认与返回视角、窄窗口和生产包。

## 第二版实现参数（2026-09-27）

在第一版基础上重做主脊岩体起伏、雪岩边缘、岩石材质和方向光。世界边界仍为 ±16 km。沿每个轴的地块细分依次为 64、192、384、192、64，总计 1,605,632 地形三角形。中央地块网格间距约 10.4 m，中景约 20.8 m；共边采样一致。增加方向性的多尺度侵蚀起伏，远离核心逐步降低细节幅度，避免远山噪点抢占主峰。

雪岩阈值与边缘经过重新设计。源岩石图采用三向投射、700 m 的艺术尺度，烘焙后通过标准材质导出；九个核心地块附带法线图，强度 .32，三处 Hero 颜色与法线均为 2048²。由此增强岩壁细节，但近距离仍受到高度场形状与 UV 分辨率约束。

柱状独立岩块试作未达到视觉目标，只保留在隐藏 WORK 集合，不进入最终网页。运行山体是连贯地形网格；不把实验柱体作为完成的岩壁。

默认相机仍为 (-6200,-7000,3700)，目标 (200,650,1750)，31mm；52 秒 FPV 使用 24mm 镜头并根据新地形重新烘焙。自由观察距离 3300–9300m，最低角度随距离限制。

网页采用 ACES、曝光 1.0。半球补光 '#a4c5f4' / '#35405b'，强度 1.1；暖色方向光 '#fff2df'，强度 3.0，Three.js 位置 (5000,6200,2500)，目标 (0,1300,-500)。主峰与中景接收和投射阴影。细腻档使用 4096² PCFSoft 阴影，阴影相机范围 ±6200 m、near 500、far 20000、normalBias 5 m；静态阴影缓存，不逐帧重算。流畅档关闭投影阴影，两档的基础纹理和几何相同。

线性雾 '#b8c5d6'，8500–23000 m。细腻档 DPR 上限 1.5，流畅档 1.0。天空保留独立 shader 与加载失败时的渐变回退；没有地形专用增强 shader 或全屏油画滤镜。
